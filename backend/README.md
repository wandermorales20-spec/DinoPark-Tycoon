# DinoPark Tycoon - Backend

## Objetivo
Este backend será el intermediario seguro entre ChatGPT y Roblox.

## Funciones
- Recibir comandos autorizados.
- Verificar la identidad del administrador.
- Publicar eventos mediante Roblox Open Cloud.
- Gestionar solicitudes de administración.
- Preparar futuras herramientas de desarrollo del juego.

## Seguridad
- Guardar las claves API como secretos privados.
- No publicar claves en GitHub.
- Validar todos los comandos.
- No permitir ejecución de código arbitrario.

## Estado
Backend pendiente de implementación y pruebas.
